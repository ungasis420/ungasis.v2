# AI Project OS Lessons

## Source fidelity

This page is a synthesis of the project template, user-provided researcher notes, prior ZIPs, and official Claude Code documentation. It is not a transcript-verified extraction from the referenced YouTube videos.

## Durable lessons

1. Context engineering is the core skill: choose exactly the right information for the next action.
2. Claude instructions should be concise; procedures belong in skills and workflows.
3. Specs should become version-controlled artifacts before non-trivial coding.
4. Verification must be part of the task, not a final afterthought.
5. AI coding should move in small, surgical changes with checkpoints.
6. A knowledge base compounds learning when raw sources and summaries are separated.
7. Autonomous loops require hard safety gates and stop conditions.
8. Non-technical teams can build useful tools when requirements are captured in plain language and translated into specs.
