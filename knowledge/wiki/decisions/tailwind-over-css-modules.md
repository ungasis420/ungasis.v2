# Tailwind CSS 4 over CSS Modules

## What
Selecting utility-first Tailwind CSS 4 over traditional CSS Modules to streamline layout styling and improve AI code generation.

## Code (if applicable)
```html
<!-- Example of Tailwind CSS utility classes -->
<div class="bg-white/[0.04] backdrop-blur-xl border-white/10 rounded-2xl p-6">
  <p class="text-sm font-semibold text-white/90">Card Title</p>
</div>
```

## When to Use
Apply to all web design projects. It ensures that styles are written inline directly where they apply.

## Gotchas
- Traditional CSS Modules require managing separate `.module.css` files, which increases agent token consumption and file read/write overhead.
