# Gemini Flash over Gemini Pro

## What
Routing documentation, template generation, and scaffolding files to Gemini 3.5 Flash (Medium) to conserve reasoning tokens for complex coding tasks.

## Code (if applicable)
```markdown
# Recommended model assignments (from MODEL_ROUTING.md)
- Scaffolding & Docs: Gemini 3.5 Flash
- Deep Debugging: Claude 3.5 Sonnet or Gemini 1.5 Pro
```

## When to Use
Apply when setting up workspace configurations, writing SOP instructions, or executing background agent tasks.

## Gotchas
- Utilizing Pro models for simple layout files consumes token limits and budget needlessly. Save Pro models for code integration and logical debugging.
