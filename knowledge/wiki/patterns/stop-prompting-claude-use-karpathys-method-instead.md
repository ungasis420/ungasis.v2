## Summary
- **Who:** Austin Marchese — AI entrepreneur (built a $25M+ startup), 35.6K subscribers [youtube.com]
- **What:** A breakdown of Andrej Karpathy's three-layer method for working with Claude AI — beyond basic prompting
- **When:** ~June 9, 2026
- **Where:** YouTube — targeting AI builders, developers, and Claude Code users
- **Why:** Because most people are "prompting Claude wrong" — Karpathy's method (Spec → Verifier → Environment) produces dramatically better results
- **How:** Three layers: (1) The Spec — define goals precisely, (2) The Verifier — evaluation criteria + second model as critic, (3) The Environment — CLAUDE.md, LLM knowledge base, skills, guardrails
- Austin Marchese breaks down Andrej Karpathy's method for working with Claude: three layers — Spec, Verifier, and Environment. [videohighlight.com]
- Layer 1 (Spec): Write precise specifications that convey your actual goal — not just the task, but the decision the output should inform. [videohighlight.com]
- Layer 2 (Verifier): Establish clear evaluation criteria before starting, and use a second AI model as a critic to validate outputs. [videohighlight.com]
- Layer 3 (Environment): Set up CLAUDE.md files, build an LLM knowledge base (wiki), create custom skills, and establish guardrails (always/ask/never rules). [videohighlight.com]
- Karpathy compares AI interaction to "summoning ghosts rather than animals" — it lacks intrinsic motivation, so you must direct it precisely.
