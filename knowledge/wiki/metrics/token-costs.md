# Token Cost Metrics

## What
A tracking table recording token consumption, file counts, and overall project costs to measure token efficiency upgrades.

## When to Use
Use to evaluate token-saving policies (like 20-Layer Token Policy and Graphify Queries) against raw consumption trends.

## Gotchas
- Free-tier keys can hit rate limits quickly under heavy usage. Implement key-rotation rules.
