# Newmont Agy Writes to Scratch Root, Not Project Subfolder

> Source: Newmont project

## Lesson
- **What happened:** Files generated by Agy (Antigravity) landed in the scratch directory root instead of the intended project subfolder, so expected outputs appeared "missing."
- **Root cause:** Agy resolves dot-paths and relative targets against its scratch root, not the project subfolder you assumed. See [[agy-cli-noninteractive-quirks]].
- **Fix applied:** After an Agy run, look in the scratch root and move files into place, or pass an explicit absolute target path.
- **Prevention rule:** Never assume Agy honored a relative subfolder. Verify output location immediately after the run and use absolute paths when placement matters.
