# Knowledge Wiki

This folder holds reusable project knowledge created from raw sources, project decisions, repeated mistakes, and validated workflows. Every single folder and file compounds knowledge to make future quests faster.

## Wiki Structure
- `patterns/`: Reusable coding styles, configurations, and layout structures.
- `gotchas/`: Documentation of bugs, configuration traps, and how to avoid them.
- `decisions/`: Architecture rationale and justifications (e.g., Next.js vs Astro).
- `metrics/`: Quantitative data showing token cost, shift duration, and agent efficiency.

## How to Add New Entries
Every new entry in the wiki must follow this exact markdown template format:

```markdown
# [Name]

## What
One-sentence description.

## Code (if applicable)
Code snippet or config.

## When to Use
Situations where this applies.

## Gotchas
Known issues or traps.

## Source
Learned in: [Project] ([Date])
Verified in: [Other projects]

## Tags
tag1, tag2, tag3
```

## Tags Taxonomy
Use the following tags strictly when categorizing wiki files:
- `design`, `css`, `js`, `react`, `nextjs`, `vite`, `powerbi`, `agent`, `workflow`, `architecture`, `performance`
