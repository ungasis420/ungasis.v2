# 04-deploy-to-revenue.md — Live to First Revenue

## Trigger
A project idea is ready to be validated, coded, deployed, and monetized.

## Steps

### STAGE 1: VALIDATE (2 hours)
Answer the 5 core validation questions in the table below:
1. **Target:** Who has this problem?
2. **Competition:** Who is the competition?
3. **Payment:** Is there willingness to pay?
4. **Scaffolding:** Can we build the MVP in <20 hours?
5. **Growth:** Can we reach 100 users in 30 days?

| Question | Answer Check | Score (1 pt each) |
|---|---|---|
| Who has this problem? (Clear target user identified) | [ ] Yes | /1 |
| Who is the competition? (Competitors analyzed simply) | [ ] Yes | /1 |
| Will users pay for it? (Willingness to pay validated) | [ ] Yes | /1 |
| Can MVP be built in <20 hours? (Under time constraint) | [ ] Yes | /1 |
| Can we reach 100 users in 30 days? (Distribution plan) | [ ] Yes | /1 |

- **Go/No-Go Decision Gate:**
  - **Score >= 4/5:** PROCEED. Scaffold the project DNA.
  - **Score < 4:** PIVOT or KILL the idea immediately. Do not write any code.

### STAGE 2: BUILD MVP (15 hours)
- Initialize using UNGASIS DNA templates.
- Code only the single core feature.
- Follow styling guidelines (glassmorphism cards, HSL gradient backgrounds, Recharts inline hex coloring).
- Split components when they exceed 200 lines.

### STAGE 3: LAUNCH (5 hours)
- Build the production site and deploy to Cloudflare Pages.
- Create a responsive landing page.
- Add payment integrations (Stripe, GCash, or buy-me-a-coffee links).
- Distribute across developer channels (Reddit, Twitter, ProductHunt, Discord).

### STAGE 4: FIRST REVENUE (5 hours)
- Share the link directly inside 10 online communities.
- Get feedback from 10 active users.
- Fix critical bugs.
- Add exactly 1 requested feature based on user feedback.

---
**Total Project Duration:** ~27 hours from idea to first ₱.

## Time to Complete
~27 hours total.

## Expected Output
A live app with active payment processing, verified user traffic, and first revenue collected.

## Gotchas
- Do not spend more than 15 hours on MVP development. Cut features ruthlessly to stay within budget.
