# 02-quest-to-mvp.md — Quest to MVP Development

## Trigger
A quest is initialized, and code creation needs to start to build the working prototype.

## Steps
1. **Define Core Feature:** Focus only on the single main feature. Cut out all nice-to-have features for now.
2. **Apply Design DNA:** Use the HSL gradient values `[30, 50, 90]` for backgrounds. Apply glassmorphism UI classes:
   `bg-white/[0.04] backdrop-blur-xl border-white/10 rounded-2xl`
3. **Execute Agent Orchestration:** Delegate code writing to Antigravity (building/scaffolding) or Cline (debugging). Keep files modular.
4. **Daily Progress Log:** Update `CONTEXT.md` after every work session with accomplished tasks and next actions.
5. **Enforce Definition of Done:**
   - Visual styling looks premium (dark glass, HSL gradient, fonts loaded).
   - Component files are under 200 lines.
   - Code runs offline without compilation errors.
   - Self-check line is logged: `Self-check: PASS — [what was checked]`.

## Time to Complete
~15-20 hours.

## Expected Output
A working prototype displaying the core feature with complete UI responsiveness and zero console bugs.

## Gotchas
- Do not add features mid-sprint (scope creep). Stick only to the single core MVP feature.
