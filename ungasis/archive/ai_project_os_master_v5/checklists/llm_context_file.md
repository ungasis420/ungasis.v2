# LLM Context File Checklist

Use before committing `LLM_CONTEXT.md` or `llms.txt`.

- [ ] Project goal is current.
- [ ] Current milestone is current.
- [ ] Commands are current.
- [ ] Key files are current.
- [ ] Architecture boundaries are current.
- [ ] Verification steps are current.
- [ ] No secrets, credentials, private keys, tokens, or connection strings.
- [ ] No customer/client/private data.
- [ ] No long tutorials or stale file-by-file dumps.
- [ ] `python scripts/verify_template.py` passes.
