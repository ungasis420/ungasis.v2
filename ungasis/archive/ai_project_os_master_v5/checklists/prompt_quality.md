# Prompt Quality Checklist

A strong prompt includes:

- [ ] Role / expert stance
- [ ] Objective
- [ ] Context and file references
- [ ] Scope and non-goals
- [ ] Constraints
- [ ] Process steps
- [ ] Output format
- [ ] Verification criteria
- [ ] Assumption policy
- [ ] Question policy

Quick formula:

```text
Act as [role]. Your goal is [objective].
Use [files/context]. Follow [constraints].
Before editing, [plan/check]. Output [format].
Verify by [test/build/manual check].
```
