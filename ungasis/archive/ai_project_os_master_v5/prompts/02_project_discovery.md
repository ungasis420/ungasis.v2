# 02 — Project Discovery Prompt

```text
Explore this project before coding.

Goals:
- identify the main architecture
- identify the key files
- identify build/test commands
- identify risks and unknowns
- suggest what should be documented in CLAUDE.md or AGENTS.md

Rules:
- read only relevant files
- do not edit files
- do not run destructive commands
- ask only blocking questions

Output:
- project map
- file map
- command map
- risk map
- recommended next action
```
