# Workflow: Continuous Improvement

At the end of each meaningful session, ask:

1. Did the same mistake happen twice?
2. Did we paste the same prompt or checklist twice?
3. Did a verification step catch an issue?
4. Did context become messy?
5. Did a rule become stale or contradictory?

## Improvement targets

- `AGENTS.md` for durable project facts/rules
- `.claude/rules/` for modular standards
- `.claude/skills/` for repeatable procedures
- `workflows/` for human operating routines
- `docs/LESSONS_LEARNED.md` for durable takeaways

Keep changes small. Do not bloat core instructions.
