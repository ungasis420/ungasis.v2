# Knowledge Base Librarian Loop

Use when raw sources or repeated lessons should become reusable project knowledge.

```text
raw source -> source card -> wiki summary -> index update -> next use
```

## Steps

1. Save source material in `knowledge/raw/`.
2. Create a source card if helpful.
3. Extract durable principles, workflows, examples, and open questions.
4. Write a focused wiki page in `knowledge/wiki/`.
5. Update `knowledge/index.md`.
6. Link related specs/docs.
7. Mark source fidelity.

## Do not

- rewrite raw files casually
- paste huge raw transcripts into wiki pages
- claim source-backed facts without a source
- mix guesses with verified notes
