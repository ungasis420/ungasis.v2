# Cross-Functional Tool Builder Skill

Use this for legal, marketing, finance, operations, HR, sales, and other non-engineering workflow ideas.

## Process

1. Capture the workflow in plain English.
2. Identify inputs, outputs, roles, frequency, and pain.
3. Map the current manual process.
4. Flag sensitive data and approval points.
5. Choose the smallest useful prototype.
6. Write a lightweight spec.
7. Define verification with realistic examples.
8. Write operating instructions for non-engineers.

## Guardrails

Require approval before sending messages, changing records, submitting forms, moving money, changing permissions, or affecting users.
