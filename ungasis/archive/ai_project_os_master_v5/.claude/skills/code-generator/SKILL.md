# Code Generator

## Procedure

1. Read the approved spec and target stack.
2. Confirm files to create or modify.
3. Generate minimal code using descriptive names and project patterns.
4. Add tests for public behavior when applicable.
5. Run syntax/tests/build checks.
6. Report files, purpose, and verification.

## Boundaries

- Do not invent architecture beyond the spec.
- Do not add dependencies without approval.
- Do not place secrets in code.
