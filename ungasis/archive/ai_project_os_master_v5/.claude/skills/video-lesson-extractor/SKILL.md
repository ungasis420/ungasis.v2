# Video Lesson Extractor

## Procedure

1. Accept pasted transcripts, user notes, or source summaries.
2. Label source fidelity: transcript / notes / metadata / memory / secondary synthesis.
3. Extract lessons into principles, workflows, prompts, skills, safeguards, and anti-patterns.
4. Map each lesson to a file that should change.
5. Avoid verbatim copying of long copyrighted content.
6. Update `docs/VIDEO_LESSON_CAPTURE.md`, `docs/SOURCE_FIDELITY.md`, and relevant workflows only after user approval.

## Output

```text
Source fidelity:
Reusable lessons:
Files to update:
Risks / uncertain claims:
Proposed patch:
```
