# Growth Experiment Loop

Use this skill for non-code AI-assisted growth work.

## Process

1. Fill `templates/growth_experiment.md`.
2. Define one hypothesis, one audience, one promise, and one action.
3. Define one metric and a pass/fail threshold.
4. Create the smallest manual execution plan.
5. Identify what AI may draft, research, analyze, or automate.
6. Add approval gates before public posts, outbound messages, spend, user-impacting changes, or customer data use.
7. After execution, record the result and lesson.

## Output

- Experiment packet
- Manual execution steps
- Approval gates
- Review checklist
- Lesson-capture path

## Guardrails

No fake proof, spam, impersonation, deceptive claims, private data scraping, or unapproved outbound/public automation.
