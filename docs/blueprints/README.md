# Blueprints Directory

This folder contains implementation-ready blueprints generated by
@blueprint-architect.

## What Is a Blueprint?
A structured spec document that converts a goal ("build champion select")
into an execution plan (tasks, files, agents, sprints, acceptance criteria).

Analogy: A blueprint is the architect's drawing. The Builder follows it
to construct the building. No improvisation needed.

## How They're Generated
1. You say: /blueprint "your goal here"
2. @blueprint-architect reads the UNGASIS knowledge base
3. Architect produces BLUEPRINT-[name].md with 8 sections
4. @quality-auditor pre-flight checks the blueprint
5. Builder executes Section 8 (kickoff prompt)

## Naming Convention
BLUEPRINT-[kebab-case-name].md
Examples:
- BLUEPRINT-champion-select.md
- BLUEPRINT-jarvis-batch-1.md
- BLUEPRINT-riftcoach-mvp.md

## How to Execute
1. Open the blueprint file
2. Go to Section 8: KICKOFF PROMPT FOR BUILDER
3. Copy-paste into Antigravity (or any agent)
4. Builder executes sprint by sprint with self-healing loop
