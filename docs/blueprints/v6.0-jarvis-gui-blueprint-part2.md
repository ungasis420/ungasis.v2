```

TASK 1: Create directory .ungasis/dashboard/
  - This is where all JSON output files will live.

TASK 2: Create scripts/startup-sequence.ps1 (max 50 lines)
  - Runs 5 Python scripts sequentially:
    1. python scripts/ungasis.py pulse --json
    2. python scripts/session-recovery.py --json
    3. python scripts/wiki-lint.py --json
    4. python scripts/token-report.py --json
    5. python scripts/cross-project.py --json
  - Each writes to .ungasis/dashboard/<name>.json
  - Log start/end time. Print summary.

TASK 3: Add --json flag to scripts/ungasis.py (pulse command only)
  - When --json passed: write output as JSON to .ungasis/dashboard/health.json
  - Schema: {"wiki_health":N,"script_count":N,"graph_nodes":N,"jarvis_score":N,"timestamp":"ISO"}
  - Default behavior (no flag) stays UNCHANGED.
  - Surgical edit only — do not refactor other commands.

TASK 4: Add --json flag to scripts/session-recovery.py
  - Write to .ungasis/dashboard/session.json
  - Schema: {"last_version":"","last_task":"","next_steps":[],"files_changed":N}
  - Default behavior unchanged.

TASK 5: Add --json flag to scripts/wiki-lint.py
  - Write to .ungasis/dashboard/wiki-health.json
  - Schema: {"total_pages":N,"health_pct":N,"orphans":N,"stale":N,"timestamp":"ISO"}
  - Default behavior unchanged.

TASK 6: Add --json flag to scripts/token-report.py
  - Write to .ungasis/dashboard/tokens.json
  - Schema: {"daily":[{"date":"","tokens":N,"model":""}],"total_tokens":N,"total_sessions":N}

  - Write to .ungasis/dashboard/lessons.json

TASK 8: If dashboard/ scaffold exists (from Agy), audit it:
  - Check npm run build passes
  - Fix any package.json or import issues
  - Wire DashboardPage to read from mock data stores

```
