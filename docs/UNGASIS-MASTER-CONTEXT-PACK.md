## Section 7: Quality System

### Scoring Dimensions (5-dimension weighted average)

| Dimension | Weight | Target Criteria |
|---|:---:|---|
| Completeness | 25% | All required files and sections exist |
| Accuracy | 25% | Technical values, paths, and patterns are correct |
| Clarity | 20% | Simple English, short sentences, explanations |
| Format | 15% | Correct markdown layout and staleness footer |
| Reusability | 15% | Modular design, clear inputs/outputs |

### Score Thresholds

| Score | Rating | Action |
|---|---|---|
| ≥ 8.0 | Excellent | Merge; log as positive pattern |
| 6.0 - 7.9 | Good | Merge; flag minor improvements |
| 4.0 - 5.9 | Needs Work | Request edit; do NOT merge |
| < 4.0 | Redo | Full reconstruction; do NOT merge |
