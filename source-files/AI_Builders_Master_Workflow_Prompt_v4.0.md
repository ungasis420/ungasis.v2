| **Row Level Security (RLS)** | Database rules that prevent users from seeing other users' data | Each customer in a restaurant can only see their own bill |
| **Environment variable** | A secret value stored safely outside your code (like a password in a locked drawer) | A recipe ingredient list kept in a locked drawer, not on the kitchen wall |
