## 5. 20-LAYER TOKEN EFFICIENCY SYSTEM

Think of tokens like a kitchen budget. Every word you send to an AI costs "mana." The 20-layer system is like 20 different money-saving tricks for your restaurant — some prevent waste, some reuse leftovers, some shrink portions:

### PREVENT (Layers 1-3): Stop waste before it starts

| # | Layer | How It Works | Savings |
|:-:|-------|-------------|:-------:|
| 1 | Pre-fill templates | Use SESSION_STARTER.md, QUEST_CONTEXT.md instead of writing from scratch | 50% |
| 2 | Knowledge file offloading | Keep modules/ on disk, reference them — don't paste into chat | 80% |
| 3 | Example-driven prompts | Show 1 example of desired output instead of explaining in paragraphs | 40% |

### OPTIMIZE (Layers 4-6): Use tokens efficiently

| # | Layer | How It Works | Savings |
|:-:|-------|-------------|:-------:|
| 4 | Route by complexity + reasoning budget | Simple tasks → small models, complex → large (MODEL_ROUTING.md) | 55% |
| 5 | Batch questions | Ask 5 things in 1 message, not 5 separate chats | 60% |
| 6 | Context pruning via Graphify | Run `graphify query` to find relevant files — reads map, not full files | 98% |

### CONTROL (Layers 7-9): Limit output waste

| # | Layer | How It Works | Savings |
|:-:|-------|-------------|:-------:|
| 7 | Structured output enforcement | Tables, JSON, bullet lists — not chatty paragraphs | 20% |
| 8 | Response length caps | "Answer in 3 sentences" or cap at 2,000 tokens | 30% |
| 9 | Incremental disclosure | Give overview first, details only on request | 50% |

### MAINTAIN (Layers 10-12): Keep sessions lean

| # | Layer | How It Works | Savings |
|:-:|-------|-------------|:-------:|
| 10 | Semantic cache | Similar questions return cached answers (planned) | 50% |
| 11 | Session checkpointing | Save progress to disk often, start fresh if context fills | 60% |
| 12 | Compact at 70% | When context window is 70% full, summarize and continue | 30% |

### ADVANCED (Layers 13-17): Deep optimization

| # | Layer | How It Works | Savings |
|:-:|-------|-------------|:-------:|
| 13 | Retrieval-based memory | Search MEMORY_BANK by keyword, inject only matching entries (max 500 tokens) | 75% |
| 14 | Tool schema pruning | Load only MCP tools needed for current task type | 70% |
| 15 | TOON compact encoding | Use pipe-delimited format instead of verbose JSON | 60% |
