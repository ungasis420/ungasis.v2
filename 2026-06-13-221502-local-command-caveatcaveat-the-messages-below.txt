## Task A: Create scripts/context-inject.py (NEW)                               
                                                                                
PURPOSE: Query knowledge graph → build hot-context.md with only relevant nodes. 
This is the core of the 70x token savings system.                               
                                                                                
HOW IT WORKS:                                                                   
1. Accept --task "description of what you're about to build"                    
2. Extract keywords from task description (split words, remove stopwords)       
3. Read graphify-out/graph.json (the knowledge graph)                           
   - Structure: {"nodes": [{"id": "...", "label": "...", "community": N, ...}], 
"edges": [...]}                                                                 
4. Search nodes by keyword match against node labels                            
5. Rank by: exact match (score 3) > partial match (score 1) > edge connections  
to matches (score 0.5)                                                          
6. Take top 15 nodes                                                            
7. For each node: extract label + connected node labels (1-hop neighbors from   
edges)                                                                          
8. Write to .ungasis/context/hot-context.md:                                    
                                                                                
   # Hot Context (auto-generated)                                               
   Task: {task description}                                                     
   Generated: {timestamp}                                                       
   Nodes: {count}                                                               
                                                                                
   ## Relevant Knowledge                                                        
   - **{node_label}**: connected to [{neighbor1}, {neighbor2}, ...]             
   - ...                                                                        
                                                                                
   ## Related Files                                                             
   - {any node labels that look like file paths}                                
                                                                                
9. Print summary: "Injected {N} nodes ({X} tokens est.) into hot-context.md"    
                                                                                
FLAGS: --task "desc" (required), --json, --top N (default 15), --dry-run        
                                                                                
FALLBACK: If graph.json doesn't exist or is empty, print warning and write      
"No graph data available" to hot-context.md. Don't crash.                       
                                                                                
Keep under 120 lines.
