# Contact Template

## Purpose
Define the standard card structure for tracking professional network contacts.

## How It Works
The Rolodex system parses contact entries stored in this format, permitting quick queries and suggesting reconnections.

## Standard Contact Card Format
```markdown
- **Name**: [Full Name]
- **Role**: [Job Title/Role]
- **Company**: [Employer/Affiliation]
- **How We Met**: [Brief meeting context]
- **Strengths**: [Key skills and expertise]
- **Last Interaction**: [Date — Brief context of interaction]
- **Notes**:
  - [Interactions history and discussion highlights]
- **Tags**: [mentor, collaborator, client, friend, expert-in-topic]
```

## Rules
1. **Consistency**: All new contact entries must follow the defined card structure exactly.
2. **Tag Standards**: Use comma-separated tags selected from the standard set.
3. **Registry Standards**: Avoid inserting contact cards directly in this template file; create separate files for each contact.

## Inputs/Outputs
| Component | Input Template | Output Blank Contact Card |
|---|---|---|
| Card Generator | Template definition | Empty markdown contact card |
