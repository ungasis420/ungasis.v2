# Learning Rules

## Purpose
Enforce consistent logging, verification, and review processes for personal and professional development.

## How It Works
The engine monitors newly completed educational milestones and prompts updates to the logs, syncing skill improvements with the project's knowledge gaps radar.

## Rules
1. **Capture Directive**: After every new learning or course completion, log it in `reading-log.md` or `skill-progress.md` within 24 hours.
2. **Weekly Skill Review**: Check and update skill levels and practice dates in `skill-progress.md` every Sunday.
3. **Monthly Reading Review**: Summarize takeaways from `reading-log.md` on the 1st of every month.
4. **Radar Integration**: Synchronize updated skill levels with `gaps-radar.md` to retire gaps as skills improve.

## Inputs/Outputs
| Component | Input Learning event | Output Radar action |
|---|---|---|
| Learning Engine | Course/Book completion details | Close gaps in `gaps-radar.md` |
