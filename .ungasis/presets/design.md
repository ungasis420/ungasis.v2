# Preset: Design 🎨
## Purpose: UI/UX design and frontend implementation
## Model Routing
- Primary: Claude Design (Tier 2) for visual design
- Secondary: Gemini Flash (Tier 1) for component generation
## Token Budget: Medium (visual descriptions + code)
## Output Format: Component code with Design DNA tokens applied
## Design DNA (Glassmorphism System)
- Base: #0a0a1a | Accent: #00d4ff | Secondary: #a78bfa
- Success: #22c55e | Warning: #f59e0b
- Glass: bg-white/[0.04], backdrop-blur-xl, border border-white/10
- ALL colors as inline hex (NEVER Tailwind color classes)
- Typography: Inter/system-ui | Spacing: 8px grid
- Motion: Framer Motion, 0.2-0.4s ease-out
## Active Plugins: Caveman, SDD
## Session Rules
- Mobile-first: touch targets ≥44px, responsive breakpoints
- Accessibility: contrast ≥4.5:1, focus rings, aria labels
- Review: "Does it feel premium? Would user say wow?"
