# OKR Rules

## Purpose
Enforce regular reviews, alignment, and scoring procedures for the OKR Engine.

## Rules
1. **Cycle Setup**: OKRs are established or revised at the start of each quarter (January, April, July, October).
2. **Weekly Update**: Update the "Current" column in `okr-current.md` during the weekly review.
3. **Monthly Check-in**: Recalculate achievement scores and flag any key results with scores `< 0.4` as "AT RISK".
4. **Task Priority**: The Commander agent references `okr-current.md` to ensure high-priority initiatives map directly to active OKRs.

## Connections
- **Portfolio**: Active projects in `portfolio-overview.md` must directly serve quarterly OKRs.
- **Task Queue**: Initiatives in `queue.md` should correspond to active Key Results.
- **Gaps Radar**: Technical skills identified for growth must bridge gaps needed to achieve KRs.
