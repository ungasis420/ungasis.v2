# Comms Templates

## Purpose
Provide standardized markdown layout templates for messages, alerts, and summaries generated by the agent crew.

## How It Works
```
Event Triggered ──> Pick Template ──> Inject Context Variables ──> Output Formatted Text
```

## Rules
1. All console alerts, notifications, and logs must follow the template formats defined below.
2. Use clear placeholders in double curly braces (e.g., `{{variable_name}}`) for dynamic fields.
3. Maintain simple, ESL-friendly English throughout the templates.
4. Always wrap table grids properly in markdown to render correctly across terminals.

## Template Index

| Template ID | Name | Channel | Use Case |
|---|---|---|---|
| COM-TMP-01 | Audit Alert | CLI Console | Inform Builder/Mel of an audit failure |
| COM-TMP-02 | Resource Alert | UI Banner | Warn Mel of low resource levels |
| COM-TMP-03 | Daily Summary | Log File | Log daily achievements and stats |

## Template Definitions

### COM-TMP-01: Audit Alert Template
```markdown
⚠️ [AUDIT WARNING]: Sprint {{sprint_name}} has failed validation.
File: {{file_path}}
Failure Reason: {{reason}}
Suggested Action: {{suggested_fix}}
```

### COM-TMP-02: Resource Alert Template
```markdown
🚨 [RESOURCE LIMIT]: {{provider_name}} is nearing capacity.
Remaining Quota: {{remaining_requests}} / {{total_requests}}
Spend Balance: ${{current_spend}} / ${{budget_limit}}
Action Taken: {{action_taken}}
```
