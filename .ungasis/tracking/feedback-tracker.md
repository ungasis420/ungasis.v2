# Feedback Tracker

## Purpose
Track which suggestions and alerts generated by automated engines are adopted or ignored by
Mel, refining suggestion algorithms over time.

## How It Works
1.
**Queueing**: When an engine or the daily pulse recommends an action, log it in
`feedback-log.md` with `Status = PENDING`.
2.
**Review**: At session close, the Commander agent reviews all pending actions, updating
status to `ADOPTED`, `IGNORED`, or `DEFERRED`.
3. **Evaluation**: Compute adoption rates monthly:
   $$\text{Adoption Rate} = \frac{\text{ADOPTED}}{\text{ADOPTED} + \text{IGNORED}} \times 100\%$$
   - **Rate < 40%**: System suggests irrelevant actions. Calibrate keywords and constraints.
   - **Rate > 70%**: High alignment. Retain rules.
