# reasoning-templates.md — Reasoning Templates

## Purpose
Provides structured formats for reasoning blocks to guide agent thinking during complex tasks.

## How It Works
The active agent copy-pastes the appropriate reasoning structure into its scratch pad or system prompt before starting.

## Reasoning Templates

### 1. Problem-Solving Template
1. **Define**: What is the core problem?
2. **Analyze**: Why is it happening? List potential causes.
3. **Solve**: What are the possible solutions? Pick the best one.
4. **Verify**: How do we check that the problem is solved?

### 2. Decision-Making Template
1. **Options**: List all available options.
2. **Criteria**: Define criteria for scoring (e.g. speed, cost, safety).
3. **Score Matrix**: Create a comparison table.
4. **Choose**: Select the option with the highest score.

### 3. Debugging Template
1. **Reproduce**: Write steps to consistently see the bug.
2. **Isolate**: Which file or code block is responsible?
3. **Fix**: Write the code fix.
4. **Test**: Run verification tests.

### 4. Architectural Design Template
1. **Requirements**: What must this system do?
2. **Constraints**: Limits on files, tokens, or performance.
3. **Design**: Folder trees, file relations, and APIs.
4. **Validate**: Check against UNGASIS engine conventions.
