# Synergy Map

## Purpose
Map and document how active projects in the portfolio share architectural patterns, rules, and configurations to reduce duplication.

## How It Works
The engine analyzes active projects and highlights direct synergies. Developers refer to this map before creating new templates or rule sets.

## Project Synergy Map
| Project A | Project B | Synergy Type | Description |
|---|---|---|---|
| **UNGASIS** | **RiftCoach** | Shared Foundation | Shared developer agent rules, token prevention systems, and DNA genomes |
| **Newmont** | **UNGASIS** | UI Patterns | Shared dashboard layouts and modern styling templates |

## Rules
1. **Synergy Definition**: Every synergy must declare a specific `Synergy Type` and description.
2. **Review Triggers**: Update the map whenever a new project is created or an existing project is archived.
3. **No Duplicate Effort**: If a synergy exists, developers must import/reference the existing resource instead of recreating it.

## Inputs/Outputs
| Component | Input Project Pair | Output Synergy Assessment |
|---|---|---|
| Synergy Mapper | Portfolio listings & DNA configs | Defined synergy row in map table |
