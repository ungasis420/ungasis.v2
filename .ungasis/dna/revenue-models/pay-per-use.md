# Pay-Per-Use Model Template

## What
A model where users pay only for the exact volume of resources they consume (e.g. API requests, server compute time, or text generations).

## Template
- **Unit Pricing:** [e.g. $0.01 per generation]
- **Free Quota:** [e.g. 50 free generations on signup]
- **Overage Rates:** [e.g. $5.00 for additional 500 generations]
- **Usage Tracking:** Client-side database or server API token counts.

---

## Example: AI Image Optimizer
A tool that compresses and updates images for web designers.
- **Price:** $0.05 per processed image.
- **Free Quota:** 20 free images per month.
- **Target:** 1,000 paid images processed = $50.00/month.
