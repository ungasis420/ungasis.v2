# Freemium Revenue Model Template

## What
A model offering basic services for free, while charging a premium fee for advanced features or expanded usage limits.

## Template
- **Free Tier Limits:** [Define usage cap, e.g. credits per day, limited features]
- **Premium Features List:** [Define high-value features, e.g. AI analysis, custom reporting]
- **Pricing Point:** [Monthly recurring rate, e.g. $4.99/month]
- **Conversion Target:** 5% to 10% of total active users.

---

## Case Study Example: RiftCoach
RiftCoach is an AI coaching tool built to help players improve in Wild Rift.

### Offer Structure
- **Free Tier:** Basic build setups, limit of 3 hero champions.
- **Premium Tier ($4.99/mo):** Access to all champions, AI reasoning feedback, custom build builders, and matchup analysis.
