# One-Time Purchase Model Template

## What
A model where users pay a single upfront price to gain permanent access to the software product or resource pack.

## Template
- **Price Point:** [e.g. $19.00 one-time fee]
- **What's Included:** [Lifetime license, offline files, HTML templates, or PDF documents]
- **Update Policy:** Free updates for lifetime, or paid upgrades for major version releases.
- **Conversion Target:** 2% to 5% of web page visitors.

---

## Example: HTML Dashboard Templates
A package of pre-built, glassmorphic layout code templates sold to other developers.

- **Price:** $29 one-time payment.
- **Included:** 5 page files, full CSS reset sheets, and surgical node scripts.
- **Hosting:** $0.00 (files delivered as zip download via email).
- **Target:** Sell to 10 buyers per month = $290/month.
