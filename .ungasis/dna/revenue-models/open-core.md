# Open-Core Model Template

## What
A model where the core software engine is released as open source (under MIT/Apache licenses), while advanced enterprise utilities or hosting features are commercialized.

## Template
- **Open-source Core Features:** [Define features in the open repo, e.g. base CLI tool]
- **Paid Premium Utilities:** [Define enterprise features, e.g. graphical dashboard, team security logs]
- **Licensing Choice:** MIT License for core repo, commercial license for premium extensions.

---

## Example: UNGASIS CLI (agy)
The tool engine is open source for anyone to download locally.
- **Open Core:** CLI commands to scaffold folders, run checks, and generate graphs.
- **Enterprise Features:** Automated remote cloud sync pipelines, team permission keys ($9.00/user/month).
