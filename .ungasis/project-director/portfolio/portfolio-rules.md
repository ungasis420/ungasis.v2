# Portfolio Rules

## Purpose
This document enforces strict regulations on active project capacity, archiving schedules, and weekly review habits.

## How It Works
The rules are used as constraints during the weekly review to prioritize work and prevent project bloat.

## Rules
1. **Active Capacity Cap**: No more than 3 active projects may be managed simultaneously.
2. **Archiving Schedule**: Automatically archive any project that has been inactive for 30 consecutive days.
3. **Weekly Review**: Review the portfolio health and status tables every Sunday.
4. **Prioritization Order**: Order projects by: Revenue Potential × Developer Energy Fit.

## Inputs/Outputs
- **Inputs**: Weekly progress status, project metrics.
- **Outputs**: Prioritized project queue, active project roster.
