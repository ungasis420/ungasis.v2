# Project Card Template

## Purpose
Provides a standard template structure to capture details, status, metrics, and metadata for each project.

## Template Layout

### 1. Metadata
- **Project Name**: [Name]
- **Status**: [Active / Paused / Complete / Archived]
- **Health**: [🟢 / 🟡 / 🔴]
- **Stack**: [Tech Stack and Versions]

### 2. Sprints & Activities
- **Current Sprint**: [Sprint Code and Name]
- **Blockers**: [List active blockers or "None"]
- **Next Action**: [Immediate next action item]

### 3. Financials & Time
- **Revenue Potential**: [Estimate in USD or models]
- **Time Invested**: [Total developer hours spent]

### 4. References & Links
- **Repository**: [GitHub Link]
- **Documentation**: [Local Codex link]

## Rules
1. **No Blank Fields**: All template placeholder blocks must be filled.
2. **Kebab-Case File**: Save project card files in the folder using kebab-case: `.ungasis/project-director/portfolio/cards/[project-name].md`.

## Inputs/Outputs
- **Inputs**: New project requirements.
- **Outputs**: Instantiated project card.
