# Research to Code Skill

## Purpose
Translate architectural findings, API reference docs, or user requirements into clean configurations, files, or code.

## Steps
1. **Read the Source Material:** Load the raw research source completely.
2. **Extract Key Facts:** Summarize all essential elements, variables, or guidelines into a structured table.
3. **Identify Deliverables:** Clarify exactly what files need to be created or modified.
4. **Draft Implementation Plan:** Lay out the proposed edits step-by-step to outline dependency order.
5. **Forge Content:** Write the code or documentation following UNGASIS styling (Simple English, tables, analogies, footers).
6. **Verify and Reflect:** Perform a quality self-check to make sure all items are correctly built.
