# Chain Registry

## Purpose
Track and register all active skill chains and record their usage statistics.

## How It Works
New chains proposed by the skill observer or generated by builders are appended to the registry. The runtime engine updates usage metrics on completion.

## Rules
1. **Dynamic Addition**: New custom chains can be registered dynamically if validated by the observer.
2. **Metrics Updates**: Every run must increment the `Uses` count and recalculate `Avg Time` and `Success Rate`.
3. **Registry Format**: Entries must follow the defined markdown pipe-delimited table format.

## Inputs/Outputs
| Direction | Format | Description |
|---|---|---|
| Input | Chain Name & Execution Result | Updates the metrics for the specified chain |
| Output | Registry Table | Provides a list of active chains and metrics for selection |
