# Module Writer Skill

## Purpose
Write a new, high-quality UNGASIS knowledge module that aligns with the style guide and repository conventions.

## Steps
1. Search the `modules/` directory (including its subdirectories) to ensure the topic does not already exist.
2. Create the file under the appropriate subdirectory in `modules/` as `ungasis-[topic].md`.
3. Apply the UNGASIS style guide standards:
   - Use simple English suitable for an ESL learner.
   - Use structured tables for details and comparisons.
   - Use checklists for any procedures.
   - Write clear analogies from cooking, sports, or everyday life to explain concepts.
4. Include the following sections in the file:
   - Title
   - Analogy
   - Core content (with comparison tables)
   - Verification checklist
   - Related modules list
5. End the file with the standard staleness footer:
   `Last reviewed: June 2026 | Review by: September 2026 | Owner: Mel`
