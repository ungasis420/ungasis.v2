# test-request.md — Test and Documentation Request Template

## Purpose
Used by the Commander to assign test suite creation or guide documentation.

## Target Agent
- **Target**: Jules/Codex 🧪

## Trigger Condition
- When a new module requires test coverage or markdown documentation guides.

## Delegation Prompt Template
```markdown
# Tests and Documentation Request

Please write tests or documentation based on the following scope:

- **Target Scope**: [SCOPE]
- **Format Required**: [FORMAT]
- **Output File Path**: [OUTPUT_PATH]

## Instructions
1. Write unit tests or documentation without changing original logic files.
2. Ensure tests use mock data where appropriate to avoid API calls.
3. Verify formatting aligns with UNGASIS style guidelines.
```
