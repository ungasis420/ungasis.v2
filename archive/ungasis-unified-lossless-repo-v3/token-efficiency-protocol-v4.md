# Token-Efficiency Protocol v4.0 - Master Reference

## 12 Layers
1. Codebase Architecture: Small files, descriptive naming
2. Instruction Files & Skills: AGENTS.md, CLAUDE.md, .cursorrules, skills
3. Verification & Planning: Plan before code, test before ship
4. Session Management: 15-20 msg cap, compact at 60-70%
5. Context Compression: Anchored Iterative Summarisation
6. Tool & Model Selection: Tier 1/2/3 routing
7. Knowledge Graphs & Memory: Graphify, Repomix, Cline Memory Bank
8. Harness Engineering: Feedforward + Feedback loops
9. Output Control: Caveman mode, surgical diffs, no filler
10. Monitoring & Auditing: Token breakdown, monthly audit
11. Model Routing (NEW): docs/MODEL_ROUTING.md
12. Context Budget (NEW): docs/CONTEXT_BUDGET.md

## Context Engineering Philosophy
Design what information flows into the agent's context window. Maximise signal-to-noise.
Always-on stays small (<=15%). On-demand loads only when needed.
Pre-tool hooks prevent wasteful reads. Fill-% zones trigger proactive management.
Model routing matches task complexity to model capability. Durable memory lives outside chat.
