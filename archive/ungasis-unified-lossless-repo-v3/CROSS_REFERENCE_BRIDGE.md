# Cross-Reference Bridge

This file tells beginners which file to open for common situations.

| Situation | Open | File |
|-----------|------|------|
| New project | Setup Wizard | `docs/SETUP_WIZARD.md` |
| Assign tasks | Agent Roles | `docs/AGENT_ROLES.md` |
| Out of context | Fill Zones | `docs/FILL_ZONES.md` |
| Choose model | Model Routing | `MODEL_ROUTING_v4.1.md` |
| Debug | Debug page | `docs/DEBUG_PAGE.md` |
| Check current work | Task Board | `TASK_BOARD.md` |
| Check shared memory rules | Shared State Protocol | `SHARED_STATE_PROTOCOL.md` |
| Check tool permissions | Permission Matrix | `docs/PERMISSION_MATRIX.md` |
| Configure MCP safely | MCP Safe Setup | `mcp/README_MCP_SAFE_SETUP.md` |

## Feynman explanation

A cross-reference bridge is a map from your problem to the file that helps.

## Layman analogy

It is like a mall directory: “Need shoes? Go to Level 2.”
