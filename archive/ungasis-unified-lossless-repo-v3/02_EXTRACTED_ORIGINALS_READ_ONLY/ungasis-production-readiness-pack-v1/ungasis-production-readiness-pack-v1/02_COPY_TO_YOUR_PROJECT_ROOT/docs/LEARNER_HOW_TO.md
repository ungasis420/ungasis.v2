# Learner How-To

## What to do first

1. Read `READINESS_LEVELS.md`.
2. Read `PERMISSION_MATRIX.md`.
3. Read `QA_TEST_PLAN.md`.
4. Fill in the blanks.
5. Ask ChatGPT to audit the project.

## What to ignore for now

If you are not technical, you can ignore:

- `.github/workflows/`
- `schemas/`
- `scripts/`

Those are useful later.

## What not to ignore

Do not ignore:

- secrets
- permissions
- tests
- rollback
- support

## Simple daily use

When you make a change, ask:

1. What changed?
2. Could this hurt data or users?
3. Did I test it?
4. Can I undo it?

## Layman analogy

You do not need to be a mechanic to check fuel, brakes, lights, and seatbelt.
