# Source Notes

These sources shaped this pack.

## GitHub Actions security

GitHub recommends least privilege for secrets and the GITHUB_TOKEN, careful secret handling, and safer workflow patterns.

URL:
https://docs.github.com/en/actions/reference/security/secure-use

## OWASP GenAI security risks

OWASP lists 2025 risks for LLM and GenAI apps, including prompt injection, sensitive information disclosure, supply chain, improper output handling, excessive agency, and unbounded consumption.

URL:
https://genai.owasp.org/llm-top-10/

## NIST AI Risk Management Framework

NIST AI RMF helps manage AI risks and improve trustworthiness across design, development, use, and evaluation.

URL:
https://www.nist.gov/itl/ai-risk-management-framework

## OpenTelemetry concepts

OpenTelemetry explains observability concepts such as signals, traces, metrics, logs, and instrumentation.

URL:
https://opentelemetry.io/docs/concepts/

## SLSA supply chain security

SLSA gives a checklist and levels for software supply chain integrity.

URL:
https://slsa.dev/
