# Release and Rollback

## Release means

Putting a new version where users can use it.

## Rollback means

Going back to the last good version.

## Before release checklist

```text
Version:
Owner:
Date:
What changed:
Tests passed:
Security checked:
Permissions checked:
Known gaps:
Rollback plan:
Approved by:
```

## Rollback steps

```text
Reason for rollback:
Last good version:
Who approved rollback:
Restore steps:
Smoke test after restore:
User message needed? Yes / No
Lesson learned:
```

## Feynman explanation

A release is a forward step. A rollback is the safe step backward.

## Layman analogy

When hiking, know the trail forward and the path back.
