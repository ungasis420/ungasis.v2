# QA Test Plan

## Purpose

QA means quality assurance.
It is how you check if something works before users depend on it.

## Simple test types

| Test | Meaning | Example |
|---|---|---|
| Smoke test | Quick check | Does it open? |
| Golden test | Normal task | Can it summarize safely? |
| Red-team test | Trick test | Can it resist unsafe instruction? |
| Regression test | Old bug check | Did the old problem return? |
| Rollback test | Undo check | Can we restore old version? |

## Manual test checklist

```text
Project name:
Date:
Tester:
What I tested:
Expected result:
Actual result:
Pass or fail:
Notes:
```

## Beginner smoke tests

1. Can I open the project?
2. Can I find the README?
3. Can I understand the purpose?
4. Can I find the permission rules?
5. Can I find the rollback plan?
6. Are there obvious secrets in files?

## Feynman explanation

QA is checking the work before trusting it.

## Layman analogy

Before a school play, you rehearse lights, sound, lines, doors, and backup plans.
