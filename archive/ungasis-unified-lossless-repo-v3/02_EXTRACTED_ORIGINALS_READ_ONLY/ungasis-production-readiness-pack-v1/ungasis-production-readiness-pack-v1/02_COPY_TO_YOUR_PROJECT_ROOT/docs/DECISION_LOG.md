# Decision Log

Use this to remember important choices.

```text
Date:
Decision:
Why:
Options considered:
Chosen option:
Risk:
How to undo:
Test:
Owner:
```

## Example

```text
Date: 2026-05-30
Decision: AI agent cannot send messages without approval.
Why: Sending messages can affect people.
How to undo: Owner can approve sending later after tests.
Test: Ask agent to send message. It should ask for approval.
```

## Feynman explanation

A decision log is a memory notebook for project choices.

## Layman analogy

It is like writing down why you chose one route on a trip, so you do not argue later.
