# Manual Smoke Tests

Smoke test means quick first check.

## Checklist

- [ ] I can open the project folder.
- [ ] I can find the README.
- [ ] I can find SECURITY.md.
- [ ] I can find the permission matrix.
- [ ] I can find the rollback plan.
- [ ] I can find the incident response plan.
- [ ] I do not see real secrets in files.
- [ ] I know who owns the project.
