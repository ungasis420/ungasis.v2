# Contributing

## Simple rule

Small safe changes are better than big risky changes.

## Before changing files

1. Read `README.md`.
2. Check `docs/READINESS_LEVELS.md`.
3. Do not add secrets.
4. Write what you changed in `CHANGELOG.md`.
5. Ask for review if the change affects users or data.

## Change request template

```text
What do you want to change?
Why?
What files change?
What test proves it works?
Can it be undone? Yes / No
```

## Beginner analogy

Contributing is like helping in a shared kitchen. Label what you changed and clean up after.
