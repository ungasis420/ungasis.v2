# Release and Rollback

## Release

A release is a version you share.

## Rollback

Rollback means going back to the last safe version.

## Before release

- checks pass
- no secrets found
- human approval done
- backup ready
- rollback steps clear

## Rollback steps

1. Stop the new version.
2. Restore the previous ZIP or tag.
3. Run smoke tests.
4. Write what failed.

## Analogy

Save your game before a boss fight.
