# Task Board Guide

`TASK_BOARD.md` is the shared work board.

## Status words

| Status | Meaning |
|--------|---------|
| Queued | Not started. |
| Active | Being worked on. |
| Blocked | Waiting on something. |
| Review | Needs checking. |
| Done | Finished and checked. |

## File lock words

| Word | Meaning |
|------|---------|
| Check | Look before editing. |
| Edit | Change the file. |
| Release | Finish and remove the lock. |

## Beginner rule

Keep tasks small enough that one task can be checked in one sitting.
