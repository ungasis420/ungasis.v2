# Observability and Logging

## Simple idea

When something happens, write down enough information to understand it later.

## Required event fields

- run ID
- time
- person or agent
- action
- tool used
- approval status
- risk level
- error if any
- rollback reference

## Feynman

Observability helps answer: “What happened and why?”

## Analogy

A receipt tells what you bought, when, and from where.
