# Connector Registry

A connector is a bridge to another service.

Examples:

- GitHub
- Gmail
- Outlook
- SharePoint
- database
- AI model API

## Rule

Every connector must say:

- owner
- auth type
- data sensitivity
- allowed actions
- forbidden actions
- approval rules
- fallback plan

## Feynman

A connector is a door to another system.

## Analogy

A bridge needs signs, weight limits, and guardrails.
