# Setup Wizard

Use this when starting a new app or project.

## 7 simple steps

1. Write the project goal in one sentence.
2. Add the target user.
3. Add the smallest useful version.
4. Pick the stage: learning, private test, public MVP, or production.
5. Fill `TASK_BOARD.md` with the first 3 tasks.
6. Add important decisions to `memory/DECISIONS.md`.
7. Run `scripts/run_all_checks.sh` before sharing the project.

## Feynman explanation

Setup means preparing the table before cooking. You do not start frying while ingredients are still missing.

## Layman analogy

It is like filling out a travel checklist before leaving home.
