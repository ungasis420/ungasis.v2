# Debug Page

Use this when something breaks.

## Debug steps

1. State what you expected.
2. State what actually happened.
3. Copy the exact error message.
4. Name the file or command involved.
5. Try the smallest safe fix.
6. Run the test again.
7. Write the lesson in `memory/GOTCHAS.md`.

## Do not do this

- Do not rewrite the whole project first.
- Do not paste secrets into chat.
- Do not delete files without backup.

## Feynman explanation

Debugging means finding the exact broken link in the chain.

## Layman analogy

If the lights go out, first check the bulb, then the switch, then the breaker. Do not rebuild the house.
