# Human Approval Gates

## Rule

AI must ask before risky action.

## Must ask before

- deleting files
- editing many files
- running shell commands
- sending messages
- changing permissions
- updating records
- submitting forms
- publishing public content
- connecting outside services
- using sensitive data
- moving money

## Approval record

Write down:

- who approved
- date and time
- exact action
- risk level
- affected files or systems
- rollback plan

## Feynman

A gate pauses danger until a human says yes.

## Analogy

Like a bank confirmation before a transfer.
