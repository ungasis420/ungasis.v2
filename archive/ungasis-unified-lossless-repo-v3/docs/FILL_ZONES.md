# Fill Zones

Use this when the AI is out of context or confused.

## Fill these zones

| Zone | What to write |
|------|---------------|
| Goal | What are we trying to finish? |
| Current file | Which file matters now? |
| Problem | What is broken or missing? |
| Expected result | What should happen? |
| Limits | What should not be changed? |
| Test | How will we know it worked? |

## Feynman explanation

A fill zone is a blank box that gives the AI the missing puzzle piece.

## Layman analogy

It is like giving a delivery driver the full address, gate code, and phone number.
