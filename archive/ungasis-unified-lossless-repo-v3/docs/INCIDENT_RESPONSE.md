# Incident Response

An incident is something bad or risky that happened.

## Examples

- secret exposed
- wrong file deleted
- AI changed too much
- public post sent by mistake
- private data copied into a prompt

## Steps

1. Stop the action.
2. Protect the data.
3. Save evidence.
4. Tell the owner.
5. Fix the cause.
6. Roll back if needed.
7. Write what was learned.

## Feynman

Incident response is how you handle a problem without making it worse.

## Analogy

Like turning off the water before fixing a leak.
