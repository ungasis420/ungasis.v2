# Handoff Prompt

This session is ending. Update docs/TASK_HANDOFF.md with:

1. Current task and status (in progress / blocked / done)
2. What was completed this session
3. What remains to be done
4. Files changed (with brief descriptions)
5. Decisions made (with reasoning)
6. Tests run and results
7. Blockers or risks
8. The single next action for the next session
