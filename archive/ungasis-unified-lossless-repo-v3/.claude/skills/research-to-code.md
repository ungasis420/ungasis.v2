# Skill: Research to Code

## When to Use
When the user asks to research a topic and then implement it.

## Steps
1. Search for relevant files and documentation
2. Summarise findings in 3-5 bullet points
3. Propose implementation plan (3-5 steps)
4. Wait for user approval
5. Implement with minimal diffs
6. Run tests from docs/TEST_COMMANDS.md
7. Report results in completion format
