# Context Engineering Checklist

- [ ] Active goal is one sentence.
- [ ] Success criteria are explicit.
- [ ] Relevant files are listed.
- [ ] Irrelevant files are excluded.
- [ ] Current errors/logs are included if debugging.
- [ ] Existing decisions and specs are linked.
- [ ] Tests/checks are named.
- [ ] Risks and forbidden actions are stated.
- [ ] A handoff exists before clearing context.
