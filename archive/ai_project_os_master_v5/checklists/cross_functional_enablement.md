# Cross-Functional Enablement Checklist

- [ ] User's workflow captured in plain language.
- [ ] Inputs, outputs, owner, and frequency identified.
- [ ] Sensitive data flagged.
- [ ] Approval points identified.
- [ ] Workflow mapped before automation.
- [ ] Lightweight spec created.
- [ ] Prototype verified with realistic examples.
- [ ] Non-engineer operating instructions written.
