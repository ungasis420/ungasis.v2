# AI Workflow Rules

- Think Before Coding: inspect relevant files, define success, and state assumptions before non-trivial edits.
- Simplicity First: choose the smallest solution that satisfies the goal.
- Surgical Changes: change only files tied directly to the request.
- Goal-Driven Execution: verify the outcome with evidence.
- Context engineering is mandatory for complex or noisy work.
- Use specs for non-trivial features.
- Use the knowledge base for reusable lessons.
- Apply the Token Budget, Checkpoint, Read-Before-Write, and Fail-Loud rules.
