# Session Closer

## Procedure

1. Summarize completed work, changed files, and verification results.
2. List open items, blockers, and next step.
3. Capture decisions in `context/decisions.md` or `docs/DECISIONS.md`.
4. Capture durable lessons in `docs/LESSONS_LEARNED.md`.
5. Suggest updates to CLAUDE.md, rules, skills, or workflows only if a pattern repeated.
6. Save a session log in `outputs/logs/` if requested.

Do not modify operating files without approval.
