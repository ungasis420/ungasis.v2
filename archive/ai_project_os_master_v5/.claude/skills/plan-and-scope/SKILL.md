# Plan and Scope

## Procedure

1. Restate the task and desired outcome.
2. Ask only blocking questions; otherwise proceed with labeled assumptions.
3. Define scope: IN, OUT, DEFERRED.
4. Define success criteria as a verifiable checklist.
5. List risks, dependencies, and files likely touched.
6. Estimate effort as Small / Medium / Large.
7. Propose implementation phases.
8. Wait for approval before making risky or multi-file edits.
