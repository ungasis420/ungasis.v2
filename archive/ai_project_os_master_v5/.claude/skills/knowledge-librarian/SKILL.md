# Knowledge Librarian Skill

Use this when source material, transcripts, notes, or repeated lessons should become durable project knowledge.

## Process

1. Read relevant source files from `knowledge/raw/` or user-provided notes.
2. Preserve raw sources as source of truth.
3. Extract durable principles, workflows, decisions, examples, and open questions.
4. Create or update focused pages in `knowledge/wiki/`.
5. Use `knowledge/schema/KNOWLEDGE_RULES.md` for formatting.
6. Update `knowledge/index.md`.
7. Separate facts, synthesis, and assumptions.

## Output

```text

Wiki pages updated:

```
