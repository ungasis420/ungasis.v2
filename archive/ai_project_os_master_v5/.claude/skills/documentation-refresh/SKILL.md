# Documentation Refresh

## Procedure

1. Identify what changed.
2. Choose the minimum docs to update.
3. Prefer linking to the source of truth over copying repeated instructions.
4. Update dates and decision status.
5. Check that README, PROJECT_START_HERE, docs, context, and workflows do not contradict each other.
6. Report files changed and any stale docs found.
