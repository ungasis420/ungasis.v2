# Research to Code

## Procedure

1. Define the decision the research must support.
2. Search project docs and code first.
3. Use official/current sources for fast-changing APIs, models, libraries, pricing, laws, or platform behavior.
4. Compare at least two options when there is a real choice.
5. Separate facts, assumptions, and uncertainty.
6. Recommend one path with tradeoffs.
7. Record the decision in `docs/DECISIONS.md` or `context/decisions.md`.
8. Implement only after approval if the choice is significant.
