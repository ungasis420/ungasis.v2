# Auto-Research Loop Skill

## Process

1. Select one improvement target.
2. Define a scoring checklist before changing anything.
3. Run or describe the before test.
4. Apply one small change.
5. Run or describe the after test.
6. Keep, discard, or retry smaller.
7. Update `docs/AUTO_RESEARCH_LOG.md` and the knowledge wiki if useful.

## Stop conditions

- Change is too broad.
- Scoring is subjective or missing.
- The change adds complexity without evidence.
- The result worsens safety, clarity, or maintainability.
