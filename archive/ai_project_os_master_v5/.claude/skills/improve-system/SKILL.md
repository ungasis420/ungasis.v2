# Improve System Skill

Use this to improve the project operating system one small experiment at a time.

## Process

1. Pick one target: prompt, skill, command, workflow, checklist, or doc.
2. Define what better means using a scoring checklist.
3. Capture the before state.
4. Propose one small change.
5. Test the after state.
6. Score before vs after.
7. Keep only if improved.
8. Record the experiment in `docs/AUTO_RESEARCH_LOG.md`.

## Rules

- One change per experiment.
- No big rewrites.
- No vague scoring.
- No keeping changes without evidence.
