# Glossary

| Term | Meaning | Source / note |
|---|---|---|
| MVP | Smallest version that proves real usefulness | Keep strict |
| Verification signal | A pass/fail check the AI or human can run | Tests, build, lint, screenshot, manual checklist |
| Handoff | Compact state summary for the next session | `docs/HANDOFF.md` |
| Skill | Reusable workflow module under `.claude/skills/` | Use when a procedure repeats |
| Subagent | Specialized AI worker under `.claude/agents/` | Use for context isolation or review |
