# 04 — Plan Before Code Prompt

```text
Create an implementation plan for this task: [TASK]

Before editing:
1. Restate the goal.
2. List relevant files.
3. List assumptions.
4. Propose the smallest safe change.
5. Define verification commands/checks.
6. Identify risks and rollback.

Do not edit until the plan is approved if the change is multi-file, risky, or ambiguous.
```
