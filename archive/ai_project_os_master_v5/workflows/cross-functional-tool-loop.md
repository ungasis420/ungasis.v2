# Cross-Functional Tool Loop

Use when a non-engineering user describes a tool or workflow in plain language.

```text
Plain-language intake -> Workflow map -> Risk check -> Spec -> Prototype -> Verify -> Handoff
```

## Steps

1. Capture the user's work in plain English.
2. Identify input, output, owner, frequency, and pain.
3. Map manual workflow before automating.
4. Check data sensitivity and approval points.
5. Convert to a lightweight spec.
6. Build the smallest useful prototype or artifact.
7. Verify with realistic examples.
8. Document how the user operates it without needing an engineer.
