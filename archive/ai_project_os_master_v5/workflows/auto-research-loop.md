# Auto-Research Loop

Use to improve prompts, rules, skills, workflows, docs, and checklists.

```text
Propose -> Test -> Score -> Keep/Discard -> Record
```

## Steps

1. Pick one target.
2. Define a scoring checklist.
3. Capture before state.
4. Make one small change.
5. Test after state.
6. Compare score.
7. Keep only if better.
8. Record in `docs/AUTO_RESEARCH_LOG.md`.
