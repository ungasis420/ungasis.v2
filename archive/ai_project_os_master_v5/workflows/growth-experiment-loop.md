# Workflow: Growth Experiment Loop

Use for AI-assisted business, marketing, content, learning, or adoption experiments.

## Loop

```text
Hypothesis -> Asset -> Manual run -> Metric -> Review -> Lesson -> Next test
```

## Steps

1. Fill `templates/growth_experiment.md`.
2. Define one audience and one promise.
3. Produce one asset or action.
4. Define the metric and pass/fail threshold.
5. Decide what AI may draft, analyze, or automate.
6. Add approval gates before public posts, outbound messages, spend, or user-impacting changes.
7. Run the smallest version manually first.
8. Review results against the threshold.
9. Save the lesson to `docs/LESSONS_LEARNED.md`.

## Done means

- experiment is ethical and specific
- metric is observable
- manual execution path is clear
- approval gates are explicit
- result is recorded
