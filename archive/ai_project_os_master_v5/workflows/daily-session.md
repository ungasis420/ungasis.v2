# Workflow: Daily Session

## Start

1. Read `docs/HANDOFF.md` and `docs/WORKLOG.md`.
2. Confirm today's single most important task.
3. Load only relevant docs/files.
4. Create or confirm a plan.

## During

1. Make small changes.
2. Verify frequently.
3. Capture decisions as they happen.
4. Avoid unrelated cleanup.

## End

1. Update `docs/WORKLOG.md`.
2. Update `docs/HANDOFF.md`.
3. Record decisions and lessons.
4. Suggest skill/workflow improvements only if repeated.
