# Test Commands

## Run All Tests
```bash
[TEST_COMMAND]
```

## Run Single Test File
```bash
[TEST_ONE_COMMAND]
```

## Run Tests in Watch Mode
```bash
[TEST_WATCH_COMMAND]
```

## Lint
```bash
[LINT_COMMAND]
```

## Typecheck
```bash
[TYPECHECK_COMMAND]
```

## Build
```bash
[BUILD_COMMAND]
```

## Notes
- [e.g., Integration tests require DATABASE_URL to be set]
- [e.g., E2E tests require the dev server running]
