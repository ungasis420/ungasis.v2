# UNGASIS v7.0 Update Pack

This folder contains a lossless upgrade pack for UNGASIS.

## Install order
1. Paste `UNGASIS_PROJECT_INSTRUCTIONS_v7.txt` into Project Instructions.
2. Upload the seven updated kernel `.md` files.
3. Upload `VERSION_MANIFEST.md` and `RESET_CHECKLIST.md`.
4. Optionally keep `MODULE_ID_MAP.md`, `SOURCE_REFERENCES.md`, and `SKILL_CANDIDATES.md` locally or upload them if useful.

## Migration style
The seven kernel files preserve the uploaded baseline and append v7 modules. No useful v4/v5 behavior is intentionally removed.

## After upload
Start a fresh Project chat and run the smoke tests in `RESET_CHECKLIST.md`.
