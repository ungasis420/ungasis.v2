# Jargon Cheat Sheet

| Word | Say it simply |
|---|---|
| Production | Real users depend on it |
| QA | Quality check |
| CI | Auto check |
| Schema | Form rule |
| Config | Settings |
| Secret | Private key |
| Token | AI text unit or access key |
| Connector | Link to another tool |
| Permission | Allowed action |
| Least privilege | Give only needed power |
| Log | Record of events |
| Observability | Seeing what happened |
| Incident | Serious problem |
| Rollback | Undo to last good version |
| Release | New version goes out |
| Eval | AI behavior test |
| Red-team | Trick test |
| Golden test | Normal trusted test |
| Supply chain | Outside parts used |
| Runtime | When it is running |
