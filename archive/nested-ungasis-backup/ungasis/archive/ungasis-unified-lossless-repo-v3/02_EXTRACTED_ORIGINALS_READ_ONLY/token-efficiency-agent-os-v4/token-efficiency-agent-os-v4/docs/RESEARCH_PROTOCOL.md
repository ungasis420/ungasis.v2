# Research Protocol (On-Demand)

> Load this file ONLY when doing research tasks.

## Depth Modes
1. **Quick** (1-2 msgs): Grep codebase, answer from existing code
2. **Standard** (3-5 msgs): Read related files, synthesise, propose
3. **Deep** (5-10 msgs): Multi-file analysis, architecture review, detailed proposal

## Rules
- State research depth before starting
- Cite file paths for all claims
- Summarise findings before proposing changes
- Do not modify code during research phase
- Present options with tradeoffs, let user choose
