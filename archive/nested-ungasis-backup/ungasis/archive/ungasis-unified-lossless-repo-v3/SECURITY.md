# Security Policy

## Report a problem

If you find a security issue, do not post secrets publicly.

Create a private note for the project owner with:

- what happened
- what file or workflow is affected
- how serious it seems
- what data may be exposed
- suggested fix if known

## Never store these in the repo

- API keys
- passwords
- tokens
- private certificates
- database URLs
- client secrets
- private client data

## Human approval required

AI or automation must ask before it:

- deletes files
- sends messages
- changes permissions
- updates records
- touches money
- touches legal, medical, HR, security, or client data
- posts public content

## Simple analogy

Security is like door locks, cameras, and rules for who gets keys.
