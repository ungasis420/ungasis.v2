# Skill: Debug One Bug

## When to Use
When the user reports a specific bug to fix.

## Steps
1. Read the error message or reproduction steps
2. Identify the likely file(s) using search, not broad reads
3. Read only the relevant section of the file
4. State root cause in ONE sentence
5. Propose fix with minimal diff
6. Apply fix
7. Run the relevant test command
8. Report: root cause, fix applied, test result
