# Project Kickoff

## Procedure

1. Read `AGENTS.md`, `CLAUDE.md`, `docs/PROJECT_BRIEF.md`, `context/domain.md`, `context/stack.md`, and `context/user-profile.md`.
2. Summarize the project in plain English.
3. Identify assumptions, missing blocking context, risks, and current constraints.
4. Define IN / OUT / DEFERRED scope.
5. Propose the first smallest useful milestone.
6. Define verification criteria before implementation.
7. Ask for approval before editing files.

## Output

```text
Project understanding:
Assumptions:
Blocking questions:
Scope in/out/deferred:
First milestone:
Verification plan:

```
