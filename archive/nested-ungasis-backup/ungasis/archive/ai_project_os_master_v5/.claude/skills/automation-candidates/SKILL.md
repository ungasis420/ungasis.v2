# Automation Candidates

## Procedure

1. Identify repeated tasks from worklogs, handoffs, and user corrections.
2. Classify each as manual checklist, prompt macro, skill, hook, script, CI check, or external automation.
3. Add human approval gates for destructive, external, production, financial, legal, security, or user-impacting actions.
4. Define logs, rollback, and failure handling.
5. Recommend only the smallest safe automation.
