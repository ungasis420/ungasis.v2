# Context Handoff

## Procedure

Update `docs/HANDOFF.md` with:

- project/task goal
- current state
- files changed
- decisions made
- commands run and results
- open blockers
- risks
- exact next step
- what not to repeat

Keep it concise enough to paste into a new chat.
