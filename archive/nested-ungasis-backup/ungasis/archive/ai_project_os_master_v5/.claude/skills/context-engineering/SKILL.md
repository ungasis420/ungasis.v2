# Context Engineering Skill

Use this when a task needs careful context curation.

## Process

1. Restate the active goal in one sentence.
2. Identify relevant files, specs, docs, decisions, logs, examples, and tests.
3. Exclude irrelevant or stale context.
4. Compress into a context pack.
5. Define verification and stop conditions.
6. Recommend whether to proceed, ask, or split the task.

## Output

```text
# Context Pack
Goal:
Relevant files:
Relevant specs/docs:
Key decisions:
Constraints:
Verification:
Risks:
Out of scope:
Next action:
```
