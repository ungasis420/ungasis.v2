# Raw Knowledge Sources

Put original or near-original source material here.

Examples:

- video transcripts
- pasted notes
- meeting notes
- issue exports
- benchmark outputs
- official docs excerpts with links
- brainstorming dumps

Rules:

1. Do not rewrite raw sources casually.
2. Add date and source link when possible.
3. Keep raw source names descriptive.
4. Convert source material into reusable pages under `knowledge/wiki/` instead of editing the raw file.
5. If source fidelity is uncertain, mark it clearly.
