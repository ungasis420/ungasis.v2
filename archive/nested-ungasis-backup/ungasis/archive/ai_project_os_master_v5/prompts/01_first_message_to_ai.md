# 01 — First Message to AI

Paste this at the start of a new project session.

```text
You are helping me start an AI-assisted project.

Read these first:
- AGENTS.md
- CLAUDE.md
- docs/PROJECT_BRIEF.md
- docs/QUALITY_BAR.md

Your task now is discovery only. Do not edit files yet.

Return:
1. Your understanding of the project
2. Stage and risk level
3. Missing context questions, only if blocking
4. Proposed MVP scope
5. Non-goals
6. Files you need to inspect next
7. First implementation plan
8. Verification plan
```
