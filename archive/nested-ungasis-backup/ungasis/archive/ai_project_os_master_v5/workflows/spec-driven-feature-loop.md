# Spec-Driven Feature Loop

Use for new features, user-facing changes, complex bugs, integrations, automations, or cross-functional tools.

```text
Interview -> Requirements -> Design -> Tasks -> Implement one task -> Verify -> Human review
```

## Steps

1. Interview for goal, user, constraints, edge cases, and success criteria.
2. Write `requirements.md`.
3. Write `design.md` with files, data, service/API, UI, risks, and tradeoffs.
4. Break into small tasks in `tasks.md`.
5. Implement one task at a time.
6. Verify and paste evidence into `acceptance.md`.
7. Ask for human review before risky or user-impacting work.
