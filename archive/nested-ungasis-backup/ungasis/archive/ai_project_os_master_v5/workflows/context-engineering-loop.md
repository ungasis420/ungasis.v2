# Context Engineering Loop

Use when a task is complex, multi-file, ambiguous, or likely to exceed a small context.

```text
Acquire -> Curate -> Compress -> Act -> Verify -> Persist -> Shed
```

## Steps

1. Acquire only relevant files, specs, errors, docs, and examples.
2. Curate what matters for the next action.
3. Compress into a context pack.
4. Act on one focused goal.
5. Verify using the strongest available check.
6. Persist durable lessons to docs, specs, context, or wiki.
7. Shed stale context with `/clear` or a handoff.

## Output

```text
Context pack:
- Goal
- Relevant files
- Relevant decisions
- Constraints
- Verification
- Risks
- Out of scope
```
