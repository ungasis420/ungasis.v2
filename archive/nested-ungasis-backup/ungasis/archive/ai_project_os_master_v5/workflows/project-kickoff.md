# Workflow: Project Kickoff

## Goal
Start with shared context, not blind coding.

## Steps

1. Fill `docs/PROJECT_BRIEF.md`.
2. Fill `context/domain.md`, `context/user-profile.md`, and `context/stack.md`.
3. Ask the AI to summarize the project and identify blocking gaps.
4. Define MVP scope: IN / OUT / DEFERRED.
5. Define verification checks before coding.
6. Create the first task packet using `templates/task_packet.md`.
7. Start implementation only after the plan is approved.

## Output

- project understanding
- first milestone
- acceptance criteria
- verification plan
- risk notes
