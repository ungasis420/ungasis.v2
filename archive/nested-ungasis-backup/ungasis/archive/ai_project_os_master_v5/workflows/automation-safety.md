# Workflow: Automation Safety

Before automating anything, confirm:

1. The manual workflow is understood.
2. Inputs and outputs are known.
3. Failure modes are listed.
4. Logs are defined.
5. Rollback or manual override exists.
6. Human approval gates exist for destructive, external, production, financial, legal, security, or user-impacting actions.

Default: checklist first, script second, external automation last.
