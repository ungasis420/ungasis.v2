# Quality Bar

Use this before accepting AI-assisted work.

## Project quality

- [ ] The user problem is clear.
- [ ] MVP scope is small enough to build.
- [ ] Non-goals are written down.
- [ ] Risks are visible.
- [ ] The next step is concrete.

## Prompt quality

- [ ] Role is clear.
- [ ] Objective is clear.
- [ ] Context/files are referenced.
- [ ] Constraints are explicit.
- [ ] Output format is specified.
- [ ] Verification criteria are included.

## Code quality

- [ ] Diff is scoped.
- [ ] Existing patterns are followed.
- [ ] Tests or checks were run.
- [ ] Edge cases were considered.
- [ ] No secrets are exposed.
- [ ] Rollback path exists.

## Documentation quality

- [ ] Decisions are recorded.
- [ ] Worklog is current.
- [ ] Handoff is enough for a new session.
- [ ] Lessons learned are reusable.

## Done means

A task is done only when the requirement is met and the verification evidence is visible.
