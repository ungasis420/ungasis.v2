# Auto-Accept Safety Checklist

- [ ] Scope is repo-local and low-risk.
- [ ] Max attempts are set.
- [ ] Tests or checks are available.
- [ ] No production systems are touched.
- [ ] No outbound messages are sent.
- [ ] No secrets are read or written.
- [ ] No data deletion or permission changes.
- [ ] Failure stop conditions are defined.
- [ ] Final report includes evidence.
