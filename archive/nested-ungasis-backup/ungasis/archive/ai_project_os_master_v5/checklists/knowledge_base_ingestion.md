# Knowledge Base Ingestion Checklist

- [ ] Raw source saved in `knowledge/raw/`.
- [ ] Source date/link/fidelity recorded.
- [ ] Wiki summary created or updated.
- [ ] `knowledge/index.md` updated.
- [ ] Facts separated from assumptions.
- [ ] Reusable workflows extracted.
- [ ] Open questions preserved.
- [ ] No raw transcript dumped into wiki without synthesis.
