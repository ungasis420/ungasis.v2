The Honest Answer

Can vscode.dev do multi-agent orchestration? Let's be direct.

❌ vscode.dev / github.dev = NOT enough

What they are: Lightweight browser editors. You open them by going to vscode.dev or pressing . on any GitHub repo.

What's missing:

  • ❌ No terminal — can't run CLI agents (Gemini CLI, Claude Code, etc.)
  • ❌ No Node.js runtime — can't install npm packages
  • ❌ Limited extensions — only "web extensions" work (most coding extensions don't)
  • ❌ No file system access — can't create/edit files outside the browser sandbox
  • ❌ No code execution — can't run tests, builds, or scripts

Good for: Quick text edits, reviewing pull requests, reading code. That's it.

✅ GitHub Codespaces = FULL power in browser

What it is: A complete Linux computer in the cloud, accessed through your browser. It looks and feels like VS Code, but has a REAL terminal, REAL file system, and can install anything.

What you get:

  • ✅ Full terminal — run any CLI agent (Gemini CLI, Claude Code, Codex CLI)
  • ✅ Node.js + npm — install any package
  • ✅ ALL VS Code extensions — Cline, Copilot, everything works
  • ✅ Full file system — create, edit, delete files normally
  • ✅ Code execution — run builds, tests, dev servers, everything
  • ✅ Copilot Agent Mode — officially supported in Codespaces

Free: 120 core-hours/month = ~60 hours on a 2-core machine. No credit card needed.

The difference: vscode.dev is like using Google Docs — you can edit text, but you can't install software or run programs. GitHub Codespaces is like having a real computer in the cloud — you can do everything you'd do on your desktop, but from any browser, anywhere.

Multi-Agent Setup in GitHub Codespaces

Step-by-step: go from zero to 4 agents running in your browser.

1

🚀 Create a Codespace (30 seconds)

Go to your GitHub repo → Click green "Code" button → Switch to "Codespaces" tab → Click "Create codespace on main".

A full VS Code opens in your browser in ~30 seconds. You now have a real Linux machine.

2

🔧 Install CLI Agents in Terminal (5 min)

# The terminal is at the bottom of your Codespace.
# Install all your agents:

# Agent 1: Gemini CLI (free, 1,000 req/day)
npm install -g @google/gemini-cli

# Agent 2: Claude Code Router (free via GLM/Kimi models)
npm install -g @anthropic-ai/claude-code

# Agent 3 (optional): Codex CLI (if Enterprise login works)
npm install -g @openai/codex

# Verify installations:
gemini --version
claude --version
3

🧩 Install Cline Extension (2 min)

In Codespaces: Click Extensions icon (sidebar) → Search "Cline" → Install.

Configure Cline to use free models via OpenRouter or Ollama (if you set up a tunnel to your local machine).

Note: Your Codespace doesn't have a GPU, so local Ollama models won't run here. Use cloud-based free models (OpenRouter, Groq free tier) instead.

4

🖥️ Set Up Split Terminals (1 min)

# In Codespaces terminal:
# Click the "+" button to add terminals, or use keyboard:
# Ctrl+Shift+` = new terminal

# Terminal 1: Gemini CLI
gemini

# Terminal 2: Claude Code (with free model)
ANTHROPIC_BASE_URL="https://open.bigmodel.cn/api/anthropic" \
ANTHROPIC_AUTH_TOKEN="your_free_glm_key" \
claude

# Terminal 3: Your dev server
npm run dev

You now have 3 agents + 1 dev server running in split terminals — all inside your browser. Plus Cline in the sidebar. Plus Copilot for autocomplete. That's 5 AI tools running simultaneously from any device with a browser.

5

🔄 Use Copilot Agent Mode from GitHub Issues (Bonus)

On any GitHub Issue, look for the "Code with Copilot Agent Mode" button in the Development section. One click → Codespace opens → Copilot starts working on the issue automatically.

This is the closest thing to "assign a task and let AI handle it" — all from the browser.

Like renting a workshop in the cloud. You walk in (open browser), all the tools are already there (terminal, VS Code, npm), you hire 3 assistants (Gemini CLI, Claude Code, Cline), they each work at their own bench (split terminals), and you supervise from the middle of the room. When you're done, you lock up (stop Codespace) and come back tomorrow.

Automate Everything (One-Time Setup)

Make your Codespace auto-install all agents every time it starts.

📦 devcontainer.json — Your "Auto-Setup Recipe"

Create this file in your project. Every time a Codespace launches, it automatically installs all your tools. No manual setup ever again.

// .devcontainer/devcontainer.json
{
  "name": "Multi-Agent Dev Environment",
  "image": "mcr.microsoft.com/devcontainers/javascript-node:22",
  
  "features": {
    "ghcr.io/devcontainers/features/github-cli:1": {}
  },
  
  "customizations": {
    "vscode": {
      "extensions": [
        "saoudrizwan.claude-dev",
        "GitHub.copilot",
        "GitHub.copilot-chat"
      ],
      "settings": {
        "terminal.integrated.defaultProfile.linux": "bash"
      }
    }
  },
  
  "postCreateCommand": "npm install -g @google/gemini-cli @anthropic-ai/claude-code && echo '✅ All agents installed!'",
  
  "forwardPorts": [3000, 5173],
  
  "remoteEnv": {
    "ANTHROPIC_BASE_URL": "${localEnv:ANTHROPIC_BASE_URL}",
    "ANTHROPIC_AUTH_TOKEN": "${localEnv:ANTHROPIC_AUTH_TOKEN}"
  }
}

This file is like a shopping list taped to the front door. Every time someone enters the apartment (opens the Codespace), the groceries (tools) are automatically delivered and put away. You never have to set up manually again.
