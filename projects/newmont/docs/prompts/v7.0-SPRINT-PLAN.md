# Newmont v7.0 QIM Sprint — Multi-Agent Build Plan
> **Method:** Two AI chefs, one kitchen, zero conflicts
> **Updated:** June 13, 2026

---

## 🍳 How This Works (The Kitchen Analogy)

You have **two chefs**:
- 🟣 **Agy (Prep Cook)** — Makes brand new dishes from scratch
- 🔵 **Claude (Head Chef)** — Fixes existing dishes + plates everything together

**The golden rule:** They NEVER touch the same pan at the same time.

- Agy **creates new files only** (files that don't exist yet)
- Claude **edits existing files only** + wires Agy's new files in
- A **merge script** copies Agy's work into the real kitchen
