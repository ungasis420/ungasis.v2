# 8. MULTI-AGENT WORKFLOW

## The Kitchen Analogy
```
🟣 AGY (Prep Cook)          🔵 CLAUDE (Head Chef)         🏛️ M365 (Architect)
Creates NEW files only       Edits EXISTING files          Plans everything
Standalone, no imports       Wires components together     Generates prompts
Works in scratch folder      Works on REAL project         Tracks progress
Cannot touch same files      Handles git, build, QA        Validates results
```

## Pattern: Foreman/Worker with File Boundary Isolation
```
WAVE 1 (PARALLEL — different files)
┌─────────────────────┬─────────────────────┐
│ 🟣 AGY              │ 🔵 CLAUDE            │
│ New files            │ Existing files       │
│ Terminal 1           │ Terminal 2           │
└──────────┬──────────┴──────────┬──────────┘
           ↓                     ↓
     MERGE STEP (merge-agy-output.ps1)
           ↓
     git add + commit
           ↓
WAVE 2 (SEQUENTIAL — Claude only)
┌─────────────────────────────────────────────┐
│ 🔵 CLAUDE                                    │
│ Integration: wire new files into app,        │
│ update routes, nav, sidebar, etc.            │
└──────────────────────┬──────────────────────┘
           ↓
     npm run build + git commit + push + tag
```

## Rules
1. **Agy creates, Claude integrates** — never the same file
2. **File boundary table** — agreed before starting, who touches what
3. **Wave-based execution** — parallel when safe, sequential when dependent
4. **Merge gate** — human runs merge script before Wave 2
5. **Goal-driven** — `/goal npm run build succeeds AND all changes committed`
6. **3-failure stop** — if same fix fails 3x, stop and ask

# 9. LESSONS LEARNED (v6.0 → v7.0)

### Agent Behavior
| # | Lesson | Impact |
|---|--------|--------|
| 1 | Agy copies project to **scratch folder** (`C:\Users\My PC\.gemini\antigravity-cli\scratch\`). Old copies get stale. **Delete scratch before re-running.** | Agy was reading v6.0 (Next.js) when real project was v6.9 (Vite) |
| 2 | Agy `--effort` flag **doesn't exist** at CLI launch. Use `/effort high` **inside** the session. | Launch command crashed |
| 3 | Claude `/goal` has **4000 character limit**. Keep it SHORT. Put details in the prompt, not the goal. | Goal rejected, had to retry |
| 4 | Agy writes files to **scratch root** (not inside a subfolder with package.json). `merge-agy-output.ps1` needs fix. | Merge script failed, Claude found files manually |
| 5 | Claude `CLAUDE.md` rules can trigger **prompt injection** warnings if phrased as "NEVER do X". Reword to positive instructions. | Claude Code flagged rules as security risk |

### Architecture
| # | Lesson | Impact |
|---|--------|--------|
| 6 | `Sidebar.tsx` is **dead code** — real sidebar is in `AppShell.tsx`. | Tasks targeting Sidebar.tsx did nothing; Claude fixed by editing AppShell |
| 7 | **Two SLACalculator files** — interactive at `src/components/`, reportability at `src/components/modules/`. | Easy to edit wrong file |
| 8 | CSV has **duplicate rows** — always deduplicate by Job Req ID (keep last). 19,292 → 18,935. | Metrics were inflated |
| 9 | Root `CLAUDE.md` at `D:\.projects\ungasis\CLAUDE.md` had leftover **PowerShell prepend block** causing injection warnings. Needs cleanup. | Recurring false positives |
| 10 | **Wave-based parallel builds** save 50%+ time vs sequential. Total v7.0: ~6 min active, ~23.5K tokens. | Proven efficient |
