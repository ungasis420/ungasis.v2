# RiftCoach Wild Rift Intelligence Database v0.6.0 — Chunk 1 Architecture Blueprint

## Purpose
Build a source-limited, Wild-Rift-only intelligence data layer for RiftCoach.

## Stage
Prototype → private beta data infrastructure.

## Active in Chunk 1
- Source policy
- Blocked-source rules
- No LoL-PC contamination rules
- Rune legality rules
- Item/boots/support slot legality rules
- Spell allowlist rules
- Gold and cooldown validation rules
- Entity schemas
- Taxonomies
- RAG/vector contracts
- Knowledge graph ontology
- Analytics/BI specs
- AI personas and guardrails

## Deferred to later chunks
- Extracted champion records
- Extracted item gold values
- Extracted champion/item/rune/spell cooldowns
- Full meta builds
- Full synergy/counter matrices

## Non-negotiable blockers
1. No LoL-PC mechanics.
2. Exact item golds require claim-level provenance.
3. Exact cooldowns require claim-level provenance.
4. Karma passive must be Mantra.
5. Generated strategy must not be labeled official.
