# Data Quality Spec

## Blockers
- Unapproved source URL
- LoL-PC source contamination
- Missing ability slot
- Pending ability names in final champion chunks
- Karma passive not Mantra
- Missing structured item gold block
- Missing structured cooldown block
- Source-verified numeric value without claim ID
- Illegal rune build
- Illegal item build
- Deprecated boots enchant in valid options
