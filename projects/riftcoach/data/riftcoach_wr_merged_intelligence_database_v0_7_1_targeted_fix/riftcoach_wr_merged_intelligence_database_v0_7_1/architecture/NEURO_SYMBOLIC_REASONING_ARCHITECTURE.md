# Neuro-Symbolic Reasoning Architecture

Symbolic rules handle legality and hard constraints. RAG/vector retrieval handles source-grounded knowledge. LLM reasoning produces contextual explanations.

## Hard symbolic rules
- Rune slot legality
- Item slot legality
- Support item slot legality
- Boots progression
- Spell allowlist
- Source allowlist
- No LoL-PC overwrite
- Gold/cooldown claim requirements
