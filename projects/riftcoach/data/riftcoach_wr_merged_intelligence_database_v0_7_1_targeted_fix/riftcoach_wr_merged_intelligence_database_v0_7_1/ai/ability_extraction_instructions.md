# Ability Extraction Instructions

1. Load the champion refresh job.
2. Open the LoL Wiki WR champion page first for mechanics and values.
3. Cross-check ability names against Riot Wild Rift champion page when available.
4. Use WildRiftFire only for guide/build context, never as the sole source for exact numeric mechanics unless the page exposes the value and the source status records that limitation.
5. Reject any URL that does not match the approved source allowlist.
6. Reject any LoL Wiki URL that lacks `/WR:` or `/WR%3A`.
7. Produce source claims for ability names, cooldowns, costs, ranges, damage values, and effect tags.
8. Do not finalize a champion if any ability name is null.
